# Version History

## v0.4

- Added an ARCore-driven virtual camera with a live VaM preview over UDP. Camera is the default page, and Joints remains available from the toolbar.
- Unified Camera and Joints in one VaM plugin on UDP 62701. Install the matching Android APK and load `PhoneController.cslist` in VaM.
- Added atom selection for scene and session plugins, camera framing, horizon alignment, movement scale presets, and stream resolution settings.
- Added Camera Grab modes for eligible joints and movable objects, plus an optional Take picture button that saves the displayed frame to Photos.
- Added optional ARCore position tracking for hands and feet on the Joints page.

## v0.3

- VaM plugin is made compatible with VaM version 1.20.77.7
- PhoneController is now a proper controller for AcidBubbles' Timeline plugin. Works you might expect, convinient.
